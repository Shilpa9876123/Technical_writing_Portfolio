# Inventory Management System User Guide

## Introduction

The Inventory Management System (IMS) is a web-based application that enables organizations to manage products, inventory, suppliers, and customer orders from a centralized platform.

The application helps users monitor stock availability, update inventory records, manage purchase and sales orders, and generate inventory reports.

This guide explains how to use the Inventory Management System.

---

## Audience

This guide is intended for:

- Inventory Managers
- Warehouse Staff
- Sales Executives
- Purchasing Teams
- System Administrators

---

## System Requirements

Before using the Inventory Management System, ensure that:

- You have a valid user account.
- You have an active internet connection.
- You are using one of the following supported web browsers:
  - Google Chrome
  - Microsoft Edge
  - Mozilla Firefox

---

## Logging In

To log in to the Inventory Management System:

1. Open the application URL in your web browser.
2. Enter your username.
3. Enter your password.
4. Click **Sign In**.

The Dashboard page opens after successful authentication.
