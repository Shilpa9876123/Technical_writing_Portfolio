|------------|--------|
| Last Updated | July 2026 |
| Product | Inventory Management System |

## Overview

This article explains how to create a new user account in the Inventory Management System.

## Prerequisites

Before you begin, ensure that:

- You have Administrator permissions.
- The user information is available.
- The user email address is valid.

## Create a User

1. Sign in to the Inventory Management System.
2. Select **Administration** from the navigation menu.
3. Click **Users**.
4. Click **Create User**.
5. Enter the following information:
   - First Name
   - Last Name
   - Email Address
   - User Role
   - Department
6. Click **Save**.

## Result

The system creates the user account and displays a confirmation message.

## Assign a User Role

1. Open the user profile.
2. Click **Edit**.
3. Select the required user role.
4. Click **Save**.

## Result

The selected permissions are applied to the user account.

## Notes

- Only administrators can create user accounts.
- User roles determine the available modules and actions.
- New users receive an email invitation to activate their account.

## Troubleshooting

### The email address already exists

Use a different email address or verify whether the user account already exists.

### The user does not receive the invitation email

Verify that:

- The email address is correct.
- The email is not in the Spam or Junk folder.
- The mail server is available.

If the issue persists, contact the system administrator.
